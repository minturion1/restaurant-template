# GrandRestaurant

GrandRestaurant is a responsive restaurant website template built with HTML and CSS.
The project showcases a clean and modern design for restaurants, cafes, or food-related businesses.

---

## 🚀 Tech Stack

* HTML5
* CSS3
* Responsive Design

---

## ✨ Features

* Modern restaurant website layout
* Fully responsive design
* Hero section with call-to-action
* Menu presentation sections
* About and contact sections
* Clean and minimal UI

---

## 🛠️ Installation

```bash id="80f2h5"
git clone https://github.com/minturion1/restaurant-template.git
```

Open `index.html` in your browser.
